# 최종 제출 요건 확인

## 확인한 근거

- 사용자가 제공한 본선 선정 안내 메일: “기한 내에 (10/31) 최종 결과보고서 제출”, “결과 보고서는 첨부파일 참고”.
- 첨부 HWP: `(양식)경북대IDEC2026창의회로설계챌린지_결과보고서_팀명_과제명.hwp`. 원본을 변경하지 않고 본문을 추출하였다.
- 주최 측 질의 답변: 지정주제 50%(MNIST baseline 대비), 자유주제 30%(다른 응용에 기법 적용), 보고서·발표 20%. 참가팀 가중치 사용 및 상수 고정 허용. 지정주제 평가는 제출 Vivado 프로젝트의 입력 파일을 hidden 파일로 교체하여 수행.

| 항목 | 확인 결과 | 최종 제출 시 조치 |
|---|---|---|
| 기한 | 안내 메일에 10/31 명시 | 정확한 마감 시각은 별도 확인. 팀 내부 완료 목표와 구분 |

| 제공 양식 | HWP 양식 제공 | HWP 필수 제출인지, DOCX/PDF도 허용되는지는 메일·양식만으로 확정 불가 |

제출용 이름 제안: `경북대IDEC2026창의회로설계챌린지_결과보고서_PPA_AdaPath-NPU` + 확장자. 이는 확인된 강제 규칙이 아닌 이름 제안이다.

## 제출 전 마지막 확인

1. 최종 DOCX/PDF가 동일 내용인지 확인하고, 제출 버전 커밋 해시를 기록한다.
2. HWP가 필요하면 최종 DOCX를 현서에게 전달한다. 이식 후 표·그림·수식·쪽번호를 다시 확인한다.
3. 지정주제는 `PPA_AdaPath_NPU_A.zip`, 자유주제는 `PPA_AdaPath_NPU_WM.zip`으로 명확히 구분한다. `PPA_AdaPath_NPU_B.zip`은 MNIST 확장 실험이다.
4. 업로드 완료 화면과 접수 확인을 별도로 보관한다. 저장소 push와 대회 제출은 서로 다른 단계다.

공개 모집 안내만으로 최종 제출 형식이나 시간을 추가 추정하지 않았다. 실제 제출은 이 검토 작업에 포함하여 실행하지 않았다.
