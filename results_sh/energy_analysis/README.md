# Easy 비율에 따른 에너지 손익분기점 분석

이 결과는 기존 VCD 기반 모드 에너지로 계산한 **분석 모델**이다. 새로운 RTL·게이트레벨 시뮬레이션, 실제 칩 측정, 정확도 예측이 아니다. 2026-10-29 main `9b192246ef0cde397824c757ad552d779532b549`의 결과를 고정하여 사용했다.

## 핵심 결과

| 질문 | 계산 결과 | 해석 |
|---|---:|---|
| Reference보다 에너지가 낮아지는 Easy 비율 | **79.09% 초과** | 경계에서는 같은 에너지. 모드별 에너지가 고정이라는 가정 |
| Baseline_A보다 에너지가 낮아지는 Easy 비율 | **46.47% 초과** | 기존 데이터패스에 적응 경로를 적용한 효과의 손익분기점 |
| 제공 동작점 Easy 96%의 평균 에너지 | **16.1575 nJ** | Reference 대비 8.9262%, Baseline_A 대비 22.3069% 감소 |
| Easy 100%에서 Reference 대비 절감률 | **11.0377%** | 이 고정 에너지 모델의 상한. 설계 전체의 이론적 상한이 아님 |
| Easy 비율이 1%p 늘 때 에너지 감소 | **0.09365 nJ** | 분포가 바뀌어도 모드별 평균 에너지가 유지될 때 |
| Easy 96%에서 Reference까지의 에너지 여유 | **1.58361 nJ/추론** | 다른 조건이 같을 때 추가 비용이 이만큼 생기면 이득 소멸 |
| Baseline_A보다 처리 cycle이 적어지는 Easy 비율 | **18.13% 초과** | 에너지 손익분기점과 다름 |

따라서 Easy 비율 약 **18.13–46.47% 구간에서는 Baseline_A보다 처리 cycle이 적어도 에너지는 더 클 수 있다.** MAC·cycle 감소율을 에너지 감소율로 그대로 해석하면 안 된다는 점을 정량적으로 보여준다. 두 경계는 반올림 표기이며 판정 계산에는 원값을 사용한다.

## 계산식과 입력

`p`는 전체 입력 중 Easy의 비율(0~1), Hard 비율은 `1-p`다. 모델 A의 선정 방식처럼 Medium이 없는 경우만 분석했다.

```
E_A(p) = p × E_easy + (1-p) × E_hard
       = 25.148294512 - 9.365370948 × p  [nJ/추론]

p_break-even = (E_hard - E_target) / (E_hard - E_easy)

C_A(p) = p × 845 + (1-p) × 1016
       = 1016 - 171 × p  [cycle/추론]
```

| 입력 | 값 | 출처 |
|---|---:|---|
| E_easy | 15.782923564 nJ | results.json → energy_nJ.A_easy |
| E_hard | 25.148294512 nJ | energy_nJ.A_hard |
| E_Reference | 17.7411468443 nJ | energy_nJ.ref |
| E_Baseline_A | 20.7966251810 nJ | energy_nJ.Abase |
| cycle Easy / Hard / Baseline_A / Reference | 845 / 1016 / 985 / 1334 | results.json → cycles |
| 제공 Easy 비율 | 0.96 | mode_ratio.A.easy |

고정된 Reference cycle 1334에 대해서는 모든 Hard 입력(1016 cycle)조차 처리 cycle이 적다. 그럼에도 모든 Hard의 에너지는 약 25.15 nJ로 Reference의 17.74 nJ보다 높다. 이 비교는 같은 clock에서의 처리 cycle 설명이며, 서로 다른 Fmax에서의 지연이나 Fmax 동작 에너지를 의미하지 않는다.

## 실험 결과와 구분해야 하는 범위

1. 입력 난이도나 임계값이 바뀌면 각 모드에 들어가는 이미지 집합도 바뀐다. 실제 조건부 에너지 E_easy와 E_hard도 달라질 수 있으므로 직선을 모든 입력 분포에 그대로 적용할 수 없다.
2. 정확도는 p만으로 정해지지 않는다. Easy 100% 지점은 정확도 제약을 만족하는 실현 가능한 동작점이라고 확인한 것이 아니다.
3. 제공 모드 에너지는 4장 Easy 런과 1 Hard+3 Easy 런을 이용한 차감 추정이다. 서로 다른 Easy 이미지의 에너지가 같다는 근사 및 reset/start 비용의 영향이 있다.
4. Reference는 12개 입력의 평균, Baseline_A는 4개 입력 평균을 사용한다. 모든 비교 대상의 동일 1,000개 입력에 대한 직접 평균 에너지 실험과 구분한다.
5. 전력 리포트와 결과 JSON은 대조했지만 원본 VCD는 저장소에 없어 측정 시간·덤프 범위와 입력별 에너지를 독립적으로 재계산하지 않았다. 신뢰구간이나 측정 오차 범위도 산출하지 않았다.

## 보고서 반영 문단

모드별 추론 에너지를 고정한 혼합 모델로 입력 분포에 따른 에너지 이득 조건을 분석하였다. Easy 비율을 p라 하면 모델 A의 평균 에너지는 E_A(p)=25.1483−9.3654p nJ이다. 이 모델에서 Reference 대비 에너지 이득은 Easy 비율이 약 79.09%를 넘을 때 발생하며, Baseline_A 대비 손익분기점은 약 46.47%이다. 제공 동작점인 Easy 96%에서는 평균 16.16 nJ로 Reference 대비 8.93% 낮다. 반면 Baseline_A 대비 처리 cycle의 손익분기점은 약 18.13%이므로, 처리 cycle 감소만으로 에너지 이득을 보장할 수 없다. 이 분석은 소수 대표 입력에서 유도한 모드 에너지를 사용하는 추정이며, 분포 변화에 따른 모드별 에너지와 정확도의 변화는 추가 실험으로 검증해야 한다.

권장 위치: 3.7 에너지 결과 다음, 또는 4.2 적용 조건·한계. 그림: `figs_sh/fig_energy_breakeven.png`와 `.svg`.

캡션: **모드별 에너지 고정 가정에서의 AdaPath_A 에너지 손익분기점. (a) Easy 비율에 따른 평균 에너지와 Reference·Baseline_A 비교. (b) Baseline_A 대비 처리 cycle과 에너지의 서로 다른 손익분기점. 곡선은 기존 결과를 이용한 계산 모델이며 새로운 시뮬레이션 결과가 아니다.**

## 재생성과 후속 연결

`python results_sh/energy_analysis/analyze_energy.py`로 JSON·101개 지점 CSV·PNG 300 dpi·SVG를 다시 생성한다. Python 3, matplotlib, Windows Malgun Gothic이 필요하다. `--input report/results.json`으로 새 수치를 적용할 수 있으나 그 경우 코드의 source_main_commit과 이 문서의 수치·근거 버전을 함께 갱신해야 한다.

현서의 임계값 스윕 결과가 나오면 TL/TH, 정확도, Easy/Medium/Hard 횟수, 평균 cycle, 데이터셋·표본 수·seed·RTL 커밋을 함께 받는다. 실제 Easy 비율을 이 곡선에 겹쳐 표시하고, 정확도 조건을 만족하는 점만 별도로 표시한다. 그 에너지는 여전히 모드 고정 모델의 예측값이므로 실제 전력 재측정과 구분한다. 새 모드별 전력 결과가 나오면 이 분석의 입력부터 갱신한다.
