# 제출본 반영용 문단

아래 문단은 수상작 언급 없이 사용할 수 있는 수정안이다. 원본 DOCX를 변경하지 않았다. 최종 측정 조건은 proofread.md의 PPA·표본·측정 창 항목을 확인한 뒤 고정한다.

## 1장 말미: 핵심 기여

본 설계의 기여는 다음 세 가지다. 첫째, Early Classifier의 상위 두 점수 차이인 Score Margin으로 입력 난이도를 판정하고, 공통 전단부 이후의 연산 경로를 선택하는 스트리밍 데이터패스를 구현하였다. Easy 입력은 후단 추론을 생략하며, Medium과 Hard 입력은 저장한 특징을 재생하여 일부 또는 전체 Conv2 채널을 사용한다. 둘째, Top-2 탐색을 두 번의 직렬 비교에서 이진 토너먼트 트리로 변경하여 판단 회로의 조합 경로를 단축하였다. 셋째, 주최 측 Reference와 항상 Hard 경로를 실행하는 Baseline_A를 함께 비교하여 데이터패스 변경 효과와 적응형 경로 선택 효과를 구분하였다. 지정주제의 모델 A는 선정 임계값에서 Easy/Hard 두 경로를 사용하며, Medium 경로의 기여는 확장 모델에서 별도로 평가하였다.

## 3.2: 회로 개선의 의미

10개 점수의 Top-2를 구하는 기존 회로는 Top-1 탐색과 해당 위치를 제외한 Top-2 탐색을 직렬로 연결하므로 최대 18개의 비교 단계가 형성된다. 개선 회로는 10개 점수와 6개 패딩 잎을 4개의 병합 레벨로 축약한다. 각 노드는 1위 값·index와 2위 값을 전달하고, 값이 같을 때의 index 우선순위를 유지한다. 여기서 4레벨은 트리의 구조적 깊이이며 4 cycle 또는 표준셀 4단을 뜻하지 않는다. 제공된 판단·제어 회로 단독 합성 결과에서 임계 경로는 4,293 ps에서 1,071 ps로 약 4.01배 단축되었고, 면적은 384.5 µm²에서 325.1 µm²로 15.4% 감소하였다. 테스트한 400,000개 벡터에서는 출력 비트가 일치하였다. 이 결과는 해당 합성 범위와 테스트 벡터에 한정되며, 칩 전체의 면적 감소나 전체 입력 공간의 형식적 동등성 증명을 의미하지 않는다.

## 3.7: 에너지와 면적의 균형

게이트레벨 시뮬레이션에서 얻은 VCD를 이용하여 전력을 추정하고, 모드별 에너지와 모드 비율로 평균 추론 에너지를 산정하였다. 제공 결과에서 Reference, Baseline_A, AdaPath_A의 평균 에너지는 각각 약 17.7, 20.8, 16.2 nJ이다. Baseline_A 대비 AdaPath_A의 에너지 감소율은 22.3%이며, Reference 대비 감소율은 8.9%이다. 두 감소율은 비교 분모가 다르므로 합산하지 않는다. AdaPath_A는 Reference 대비 평균 실행 MAC을 23.8% 줄이지만, 특징 저장과 Early Classifier 및 제어 회로의 비용으로 에너지 감소율은 이보다 작다. 또한 셀 면적은 32,085 µm²에서 49,858 µm²로 55.4% 증가한다. 따라서 본 결과는 면적을 추가로 사용하여 추론 지연과 에너지를 줄인 동작점으로 해석한다.

## 3.7: 효율 지표 정의

실효 TOPS/W는 실제 수행한 연산 수를 추론당 에너지로 나눈 값이며, 1 MAC을 2 operations로 계산한다. 등가 TOPS/W는 모든 설계에 동일한 Reference 연산 수를 적용하여 같은 분류 작업을 완료하는 에너지 효율을 비교한 값이다. 연산 생략형 설계에서는 두 지표의 의미가 다르므로 평균 에너지(nJ/추론), 정확도, 실행 MAC과 함께 제시한다. Baseline_A에는 Early Classifier가 없으므로 실행 MAC은 58,080이며, 제공 에너지 기준 실효 TOPS/W는 약 5.59이다.

## 4.2: 평가 범위와 한계

주최 입력에 대한 RTL 정확도 평가는 고유 100개 이미지가 10회 반복되는 1,000회 입력 조건이므로, 1,000개의 독립 이미지에 대한 일반화 평가와 구분한다. 임계값을 테스트셋에서 탐색한 결과는 해당 데이터의 동작점 탐색 결과이며, 독립 검증셋에서 임계값을 고정한 후 미사용 테스트셋을 평가하는 절차가 추가로 필요하다. 전력은 소수 대표 입력의 게이트레벨 VCD에 기반한 pre-layout 추정이며, 실리콘 계측 결과가 아니다. 배치·배선, 클럭망 및 실제 입력 분포를 반영한 후속 검증이 필요하다. WM-811K의 에너지 수치는 10-class 확장 모델의 모드별 에너지를 적용한 대리 추정이므로, 4-class 설계의 직접 전력 측정 결과와 구분한다.
