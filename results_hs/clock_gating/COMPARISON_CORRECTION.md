# 1번 결과의 비교 기준 정정 — 서현 전달

## 보고서에서 구분할 두 주장

기존 보고서의 **Reference 대비 28.7%**는 본 실험에서 동일 조건으로 재현한 값이 아니다. 이번 실험은 **AdaPath 모델 A의 게이팅 미적용 설계 대비 ICG 적용 설계**를 비교하였다. 두 값은 분모와 비교 설계가 다르므로 새 감소율로 기존 28.7%를 대체하거나, 기존 28.7%가 검증되었다고 서술해서는 안 된다.

## 권장 위치와 교체 문단

기존 28.7% 수치의 해석 문장 옆에 비교 기준을 명시하고, 별도의 '클럭 게이팅 적용 전후 검증' 문단에 다음을 반영한다. 이 파일은 편집 제안이며 보고서 원문은 수정하지 않았다.

기존 Reference 대비 에너지 추정과 구분하여, AdaPath 모델 A 내부의 클럭 게이팅 적용 전후를 동일 조건에서 비교하였다. 전용 ICG 셀을 포함한 설계를 합성하고 게이트 수준 VCD의 스위칭 활동도를 이용하여 전력을 재평가하였다. 선정한 Easy·혼합·Hard 구간의 전력 및 에너지 추정 감소율은 각각 25.926%, 25.177%, 20.743%였다. 후속 고유 입력 40개 분석에서는 Easy 36개 구간 평균 에너지의 감소율이 25.8629%였으며, 해당 파일의 Easy/Hard 구성비를 적용한 가중 에너지 추정 감소율은 25.5934%였다. 후자는 모드별 표본 결과를 결합한 값으로 전체 입력 직접 측정값이 아니다. 이 결과는 게이팅 적용 전후의 합성 후 비교 근거이며, Reference 대비 기존 28.7%의 재검증 결과는 아니다.

## 캡션

AdaPath 모델 A의 게이팅 미적용 설계 대비 전용 ICG 적용 설계의 전력·에너지 추정 비교. ASAP7 RVT TT, 0.7 V, 25°C, 100 MHz 및 동일 입력을 사용하였다. Reference 설계와의 비교가 아니며, 배치·배선과 물리적 CTS를 포함하지 않는다.

## 반드시 유지할 한계

- 전후 설계를 각각 합성하여 매핑 차이도 포함하므로 절감분 전부를 단일 게이트의 순수 인과 효과로 분리하지 않는다.
- 실리콘 실측·배치배선 후 검증을 수행한 것으로 표현하지 않는다.
- 40개 분석의 기존 편차는 9개 Easy 구간 평균의 편차이다. 추가 이미지별 실험 완료 후에는 해당 실험의 초기화·관측 창 조건을 구분하여 별도로 기술한다.
- 원래 Reference 대비 주장을 직접 검증하려면 Reference도 동일 가중치 인터페이스·도구·입력·제약·전력 창에서 별도로 재평가해야 한다. 이번 문서 정정은 그 실험을 수행한 것으로 가장하지 않는다.
