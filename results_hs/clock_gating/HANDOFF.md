# 서현 전달: 실제 ICG 적용 후 전력 재평가

## 반영 권장 위치

기존 전력·에너지 분석의 클럭 게이팅 상한 추정 뒤에 **「전용 ICG 셀을 적용한 배치 전 전력 평가」** 소절을 추가한다. 기존 28.7%를 실측값처럼 치환하거나, 아래 수치를 Reference 대비 개선율로 사용하지 않는다. 이 문서는 별도 실험 결과 전달용이며 보고서 원문은 변경하지 않았다.

## 보고서 반영 문단

클럭 활동 억제가 전력 감소로 연결되는지를 평가하기 위하여 모델 A의 후단 Conv2, Pooling 및 FC 경로에 ASAP7의 전용 ICG 셀(ICGx1_ASAP7_75t_R)을 적용한 별도 설계를 구성하였다. 기준 설계와 게이팅 설계를 동일한 Yosys·OpenROAD 환경, ASAP7 RVT TT 조건 및 100 MHz에서 비교하였다. 합성 넷리스트에 동일한 버퍼 셀과 최대 분기 수 4의 클럭 트리를 구성하여 셀 부하와 버퍼 비용을 포함하였으며, 실제 배치·배선에 의한 RC는 포함하지 않았다. 무지연 게이트 수준 시뮬레이션의 VCD를 이용하여 각 구간의 평균 전력을 계산하고, 구간 길이를 곱한 뒤 처리 이미지 수로 나누어 이미지당 에너지를 산출하였다. 초기화 및 시작 구간을 포함한 관측 창은 두 설계에서 동일하게 유지하였다.

Easy 4장 구간의 평균 전력은 2.616231 mW에서 1.937954 mW로 감소하였고, 이미지당 에너지는 22.444645 nJ에서 16.625705 nJ로 감소하여 25.926%의 감소율을 보였다. Easy 3장과 Hard 1장을 포함한 혼합 구간에서는 2.758922 mW에서 2.064295 mW로, Hard 4장 구간에서는 2.916748 mW에서 2.311740 mW로 감소하였다. 두 구간의 에너지 감소율은 각각 25.177%, 20.743%였다. Hard 입력에서도 후단이 매 주기 동작하는 것은 아니므로 게이팅 효과가 관찰될 수 있으나, 본 결과는 해당 입력·관측 창에 한정된 비교이다. 별도 합성에 따른 조합논리 매핑 차이도 포함되므로 감소분 전체를 ICG 셀 단독 효과로 분리하여 주장하지 않았다.

기능 보존 여부는 두 단계로 확인하였다. 전용 ICG를 포함한 RTL의 1,000회 순차 입력 대조에서 두 설계 모두 970회 정답, 평균 851.84 cycle, Easy/Medium/Hard=960/0/40을 보였으며 decision·mode·margin·cycle의 불일치는 0건이었다. 최종 버퍼 넷리스트에서는 세 구간의 각 4회 실행을 두 설계에서 수행하여 총 24회의 출력이 각각 기준 RTL과 일치함을 확인하였다. Hard 구간의 두 오분류도 기존 RTL과 동일하였다. VCD 활동도 적용 누락은 모든 구간에서 0개였다. 10 ns 제약의 배치 전 propagated-clock STA에서 기준/게이팅 설계의 최소 setup slack은 각각 +6.233199/+6.224182 ns, 최소 hold slack은 +37.778517/+35.425427 ps였다. 보고된 slew·capacitance·fanout 위반은 없었다. 이 결과는 배치·배선 후 타이밍 보증을 의미하지 않는다.

본 평가는 실리콘 실측이 아닌 라이브러리·활동도 기반 배치 전 추정이며, 물리적 CTS, 배선 기생성분, 다중 PVT 및 지연에 의한 글리치 전력을 포함하지 않는다. 세 측정 구간은 12회 실행에 사용한 11개 고유 입력으로 구성되므로 전체 데이터셋의 평균 절감률로 일반화하지 않았다. 또한 이번 순차 기능 대조에 사용한 input_1000.txt는 100개의 고유 픽셀 배열이 각각 10회 반복된 파일로 확인되어, 1,000개의 독립 표본을 이용한 일반화 평가와 구분하였다. 같은 조건의 Reference 재측정은 수행하지 않았으므로 기존 Reference 대비 개선율과 직접 결합하지 않았다.

## 표·그림 캡션

**표. 전용 ICG 적용 전후의 구간별 배치 전 전력·에너지 비교.** ASAP7 RVT TT, 100 MHz, 동일한 팬아웃 제한 버퍼 모델을 적용하였다. 각 구간은 4회 추론이며 reset·start 시간을 포함하였다. 에너지는 VCD 구간 평균 전력×관측 시간÷4로 계산하였다. 비교 대상은 AdaPath A의 기준/ICG 변형이며 Reference 비교가 아니다. 수치는 라이브러리 기반 추정값이다.

**그림. 입력 경로 구성에 따른 ICG 적용 전후 이미지당 에너지.** Easy, 혼합(Easy 3장·Hard 1장), Hard 구간의 감소율은 각각 25.926%, 25.177%, 20.743%였다. 동일 관측 시간에서 전력 및 에너지의 감소율은 같으며, 입력 모집단 전체의 평균을 뜻하지 않는다. 오차막대를 제시할 독립 반복 실험은 수행하지 않았다.

## 제출 전 표현 점검

- 사용 가능: “선정한 세 구간에서 배치 전 전력·에너지 추정값이 20.743~25.926% 감소하였다.”
- 사용하지 않음: “실측 전력 26% 감소”, “모든 MNIST 입력에서 평균 26% 절감”, “Reference 대비 26% 개선”, “물리 설계 타이밍 검증 완료”.
- 기존 상한 추정 28.7%와 새 결과는 분석 대상·모델이 다르므로 직접적인 오차율이나 실측 검증률을 계산하지 않는다.
