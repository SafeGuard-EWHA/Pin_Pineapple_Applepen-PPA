1번 교정 완료

보고서 28쪽 하단으로 넘치던 고유 입력 40개 확장 문단을 29쪽 시작으로 옮겼다. 최종 쪽수는 43쪽이며 본문, 수치, 표 32개, 그림 32개 내용은 유지하였다. Word에서 목차와 필드를 갱신하고 PDF를 다시 내보냈다.

자유주제 전력 패키지는 넷리스트 2개, 표준셀, 가중치, 입력 및 SDC를 포함한다. run_wm.sh와 power_wm.sh의 경로 및 오류 처리를 정리하였다. TB와 기존 RTL은 수정하지 않았으며 컴파일 옵션으로 데이터 경로만 지정한다. 외부 도구와 ASAP7 Liberty/LEF는 ORFS 설치본을 사용한다. README 8절에 실행 방법을 추가하였다.

기존 8.8% 수치는 변경하지 않았다. 새 패키지의 전체 재실행은 아직 완료하지 않았고, 파일 해시 및 스크립트 문법과 ZIP 구성을 검증하였다. 다음 동일 입력 실험에서 양쪽 설계를 이 PC에서 검증한다.

서현 권장 반영: report/make_final_report.py, DOCX/PDF, submission의 수정 패키지를 함께 가져간다. 기존 수치나 설계 개선으로 해석하지 않는다.
