수정 전 집계는 cycle 기준값이 없는 경우도 일치로 계산하였다. 제외 대상은 기본 시드의 `OBS n=123 idx=1000 dec=5`이며 관측 cycle은 1,018이다. 이 값에 대응하는 기준 cycle이 없으므로 불일치나 일치로 판정하지 않았다. 판정 값 5의 비교 근거는 동일 xfill 조건의 RTL 실행이다.

## 서현 전달 문단

합성 넷리스트의 5개 시드 부분 실행에서 채점 출력 1,007개의 판정이 RTL과 일치하였다. 처리 cycle은 기준값이 있는 1,006개 출력에서 모두 일치하였으며, 기준값이 없는 인덱스 1000의 치환 출력 1건은 cycle 대조에서 제외하였다. 이 결과는 부분 실행의 합계이며 원본 TB 한 번의 1,000회 실행 완료를 의미하지 않는다.

권장 위치는 3.5.7절, 표 11 마지막 행, 표 15 및 결론이다. 브랜치의 DOCX/PDF에는 이미 반영하였다. 그림 17의 캡션은 “아래 콘솔의 집계는 교정 전 값이다(cycle 대조 1건 제외, 표 15)”라고 구분하였다. 그림 번호는 보고서 생성 시 LBL로 연결하였다.

```text
python evidence/vivado_netlist/scripts/compare.py evidence/vivado_netlist/logs/net_seed_default.log results_hs/corrected_tb/sequential.csv
```

5개 로그 모두 개별 compare 결과와 summary 결과를 대조하여 일치를 확인하였다. 원시 로그 SHA-256, 제외 사례 및 비교 결과는 `validation.json`에 있다. 보고서는 Word 16.0에서 목차와 필드를 갱신하고 PDF로 내보냈으며 43쪽, 그림 32개, 표 32개를 유지하였다. 전 페이지 렌더링을 확인하였고 미치환 참조, 이중 퍼센트 및 가운데점이 없음을 검사하였다. DOCX 표의 변경은 표 3, 11, 15에 한정되며 포함된 이미지 파일은 원본과 동일하다. 생성 스크립트의 CRLF 줄바꿈을 유지하였다.
