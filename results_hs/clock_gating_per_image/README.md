# 이미지별 에너지: 실행 전 계획

기존 4영상 구간의 평균을 개별 이미지의 측정값으로 사용하지 않는다. 표본 확대 실험에서 고정한 동일한 고유 입력 40개(Easy 36, Hard 4)를 두 설계에서 각각 독립적으로 실행하여 총 80개의 이미지/설계 측정값을 얻는다. Hard도 이번에는 새로 실행한다. 기존 RTL·보고서·제출 ZIP은 변경하지 않는다.

기존 검증 TB를 별도 실행 디렉터리에 복사하고 컴파일 옵션 `N_IMG=1`을 적용한다. 이미지마다 fresh simulation의 reset/start 및 초기화 활동을 포함한다. 에너지는 단일 영상 VCD의 평균 전력×관측 시간으로 계산하며 4로 나누지 않는다. 기존 4영상 구간은 초기화 활동을 공유하므로 그 평균과의 수치 차이를 오류로 단정하지 않는다.

계획: Easy, Hard 및 선택 표본 40개 전체에 대해 개별 에너지의 평균·표본 표준편차(n−1)·최소·최대와 전후 paired 감소율을 제시한다. 36:4 선택 표본 평균과 입력 파일 96:4 구성비 가중 추정을 구분한다. Hard 4개 표준편차는 해당 파일 내 Hard 고유 입력 전수의 기술통계이며 일반화 추론이 아니다. 단일 실행씩이므로 재실행 측정 오차의 표준편차를 의미하지 않는다.

각 출력·cycle은 전체 기준 RTL 로그와 비교하며 전력 활동도 누락 0 및 설정된 STA 제약 통과를 검사한다. 원시 파형은 SHA-256 검증 후 무손실 gzip으로 로컬 보관한다. 로그·개별 수치·검산 코드·재현 정보를 Git에 제공한다. `run_per_image.py --limit 2`로 첫 한 쌍을 점검한 후 기본 80으로 이어갈 수 있다. 이미 완료한 기록은 건너뛰되 미완료 파형이 있으면 임의 덮어쓰기 없이 멈춘다.

ASAP7 RVT TT 0.7V/25°C, 100 MHz, 기존 buffered_v2 넷리스트를 사용한다. 배치·배선·실제 CTS·기생성분·SDF 글리치·다중 PVT를 제외한 합성 후 전력 추정이라는 한계는 유지된다.
