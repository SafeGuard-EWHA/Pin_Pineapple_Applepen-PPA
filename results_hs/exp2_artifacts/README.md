## 실험 및 검증

- 모델 A, TL=TH=63, AdaPath VARIANT=2와 항상 Hard인 VARIANT=0 비교.
- 두 설계는 이 테스트벤치에서 같은 모델 A 가중치를 사용한다. 별도 학습한 Baseline 모델이나 Python float 추론 실험이 아니다.

- 입력은 고유 100장 × 10회 반복. 독립 표본 1,000개로 통계적 유의성을 해석하지 않는다. 가우시안 열화는 반복 위치마다 잡음이 다를 수 있지만 새로운 독립 원본 이미지가 되는 것은 아니다.

- 원본과 contrast .3의 AdaPath 기준값을 먼저 재현한 뒤 전체 실행했다. 두 기준점 모두 일치했다.
- 34조합 누락·중복 없음, 각 모드 합 1,000, 모든 실행 valid_out 1,000/1,000, Medium=0, 모든 Baseline Hard=1,000 및 평균 985.00 cycle 확인.

## 보고서 반영 문단

입력 열화에 따른 적응형 경로 선택을 평가하기 위해 모델 A에 대비 감소, 3×3 평균 블러, 가우시안 잡음을 적용하고 고정 임계값 TL=TH=63에서 RTL 시뮬레이션을 수행하였다. 원본 입력에서 AdaPath와 항상-Hard 비교 설계는 모두 97.0%의 정확도를 보였으며, AdaPath는 평균 851.84 cycle로 비교 설계의 985.00 cycle 대비 13.52% 적은 사이클을 사용하였다. 대비가 1.0에서 0.2로 감소하면 Hard 비율은 4.0%에서 72.0%, 평균 사이클은 851.84에서 968.12로 증가하였다. 측정한 블러 및 잡음 강도 구간에서도 Hard 비율과 평균 사이클이 증가하여 입력 변화에 따른 연산 배분을 확인하였다.

다만 연산량의 적응적 증가가 정확도 보존을 보장하지는 않았다. 블러 4회에서 AdaPath와 비교 설계의 정확도는 각각 87.0%, 90.0%였고, 가우시안 잡음 σ=100에서는 각각 74.9%, 83.0%로 8.1%p 차이가 발생하였다. 이는 열화 환경에서 조기 종료 판단의 한계를 보여준다. 높은 확신의 오분류가 가능한 원인이나, 본 집계 결과만으로 개별 오분류의 경로와 원인을 직접 입증할 수는 없다. 추가적인 샘플별 decision·margin·mode 로그 분석이 필요하다.

## 권장 위치와 그림 캡션

- 권장 위치: 성능 평가의 입력 열화/강건성 절, 한계 논의 절.
- `fig_robustness_modes.png`: 입력 열화 강도에 따른 모델 A의 Hard 경로 비율과 평균 cycle. TL=TH=63이며 Medium 경로는 선택되지 않는다. Baseline은 동일 가중치를 사용하는 항상-Hard RTL 설계이다.
- `fig_robustness_acc.png`: 대비 감소·블러·가우시안 잡음 조건에서 AdaPath와 항상-Hard 설계의 정확도 비교. 강한 블러와 잡음에서 나타난 정확도 차이를 함께 제시한다.
- 그림은 원본 plotting script가 생성한 200 dpi PNG이며, 300 dpi/SVG로 표시하지 않는다.
- 본 결과는 모델 A의 두 경로 동작점 평가이며 3단계 Medium 이득이나 Margin 대 entropy의 직접 비교가 아니다.
- 정확도는 열화 강도에 따라 반드시 단조 감소하지 않는다. 원본 97%에서 대비 .5 조건은 두 설계 모두 99%였다.
